# Couchsurfing Growth Audit

**Live → https://eddieatadapty.github.io/couchsurfing-flow-rebuild/**

Five ideas to turn more Couchsurfing users into subscribers, each built into a clickable version of Couchsurfing's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Show them hosts before the price | +10–20% CR to purchase |
| 02 | Let them write the request, then join to send it | +5–15% CR to purchase |
| 03 | Make the yearly saving impossible to miss | +10–15% ARPU · annual mix |
| 04 | Catch the people who close the paywall | +5–10% ARPU · second chance |
| 05 | Offer verification after they join, not as a surprise | +5–10% ARPU · verification attach |

Every price, rating and feature comes from Couchsurfing's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Couchsurfing. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
